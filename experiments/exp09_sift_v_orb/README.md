## Experiment 9: SIFT vs ORB

### Goal
Compare classical feature extraction methods.

---

## Observations

- ORB is faster but less robust to scale changes
- SIFT provides more stable and accurate matches
- SIFT handles rotation and scale better than ORB

---

## Key Insight

There is a trade-off between:
- Speed (ORB)
- Robustness (SIFT)

---

## Conclusion

- ORB is suitable for real-time applications
- SIFT is better for accuracy-critical tasks
